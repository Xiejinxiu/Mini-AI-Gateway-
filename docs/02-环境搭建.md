# 02 · 环境搭建（M0）

> 目标：30 分钟内搞定，然后立刻进 M1。**这一步不许拖成一天。**

---

## 一、你机器上的现状（我已探明）

| 项 | 状态 | 处理 |
|---|---|---|
| `JAVA_HOME` | ❌ 指向 `D:\software\jdk\jdk8` | **必须改成 17** |
| JDK 17 | ✅ 已存在：`D:\software\jdk\ms-17.0.15`（17.0.15 LTS） | 直接用 |
| Maven | ✅ 3.9.10，阿里云镜像已配 | 不用动 |

## 二、Step 1：切到 JDK 17

**为什么要改**：Spring Boot 3 编译需要 Java 17 字节码，JDK 8 会直接报
`java: 无效的目标发行版: 17` 或 `UnsupportedClassVersionError`。

**怎么改（图形界面，最稳）**：

1. `Win + R` → 输入 `sysdm.cpl` → 回车
2. **高级** → **环境变量**
3. 在**系统变量**里找到 `JAVA_HOME` → **编辑** → 改成：

   ```text
   D:\software\jdk\ms-17.0.15
   ```

4. 在**系统变量**里找到 `Path` → 编辑 → 确认里面这一条存在，**并且排在 jdk8 那条之前**：

   ```text
   %JAVA_HOME%\bin
   ```

   如果里面有 `D:\software\jdk\jdk8\bin` 这样的**硬编码路径**，删掉它（或移到 `%JAVA_HOME%\bin` 后面）。
5. 如果**用户变量**里也有 `JAVA_HOME` 或 `Path` 指向 jdk8，同样处理。用户变量优先级高于系统变量，这是最常见的坑。
6. **关掉所有终端窗口和 IDEA**，重新开一个 PowerShell。

**验证（必须三条都过）**：

```powershell
java -version        # 期望：openjdk version "17.0.15"
javac -version       # 期望：javac 17.0.15
mvn -v               # 期望：Java version: 17.0.15, vendor: Microsoft
```

> `mvn -v` 输出的 Java version 必须也是 17 —— mvn.cmd 读的正是 `JAVA_HOME`。
> 如果 `java -version` 是 17 但 `mvn -v` 还是 1.8，说明 `JAVA_HOME` 没生效，回去看用户变量。

## 三、Step 2：Git 基础配置

```powershell
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"
git config --global core.autocrlf false      # Windows 上避免满屏换行符 diff
git config --global init.defaultBranch main
```

然后在 `D:\projects\new_project` 里：

```powershell
git init
```

**第一件事是创建 `.gitignore`**（自己敲，别复制，你知道每行在挡什么）：

```gitignore
# 编译产物
target/
*.class

# IDE
.idea/
*.iml
.vscode/

# 本地私有配置（放 API Key 的）
*.local.yml
*.local.properties
.env

# 日志
logs/
*.log
```

> 🔴 **`.gitignore` 一定要在第一次 commit 前写。** 一旦 API Key 进了 Git 历史，清理起来极其痛苦。这是真实工程事故。

## 四、Step 3：IDEA 配置

打开 IDEA → `Customize` / `Settings`：

1. **Project Structure → SDK**：添加 `D:\software\jdk\ms-17.0.15`，语言级别选 17
2. **Build Tools → Maven**：
   - Maven home path → `D:\software\apache-maven-3.9.10`
   - User settings file → `D:\software\apache-maven-3.9.10\conf\settings.xml`（勾上 Override）
   - Local repository → 应自动识别为 `D:\software\apache-maven-3.9.10\mvn_repo`
3. **Editor → File Encodings**：全部 UTF-8
4. **Build → Compiler → Java Compiler**：Target bytecode version = 17
5. **插件**：先什么都别装。等你真觉得烦了再装（Lombok 之类）。

---

## 五、Step 4：创建两个空项目（M1 要用）

用 IDEA 的 **Spring Initializr**（`New Project → Spring Boot`）：

### 项目 A：`mock-backend`
| 项 | 值 |
|---|---|
| Group | `com.yourname.gateway` |
| Artifact | `mock-backend` |
| Type | Maven |
| Language | Java |
| JDK | 17 |
| Packaging | Jar |
| Dependencies | **Spring Web** 一个就够 |

### 项目 B：`gateway`
同上，Artifact = `gateway`，依赖也**只要 Spring Web**（M1 阶段 Spring Web 甚至只是给你个跑起来的壳，转发逻辑你会用 JDK 的 HttpClient 手写）。

放好位置：

```text
D:\projects\new_project\mock-backend\
D:\projects\new_project\gateway\
```

> ⚠️ **Phase 1 不要加任何其它依赖。** 没有 Lombok、没有 WebFlux、没有 Redis。
> 每多一个依赖，你就多一个"出问题不知道是谁的锅"的可能。

**验证**：两个项目分别 `mvn -q spring-boot:run`，看到 `Tomcat started on port(s): 8080` 就算过。
记得给 `mock-backend` 改端口（`src/main/resources/application.yml`）：

```yaml
server:
  port: 8081
```

## 七、Phase 3/4 才需要的东西（现在只看，不要装）

留在这里免得你忘了，但**现在一律不装**：

| 里程碑 | 要装什么 | 建议方式 |
|---|---|---|
| M6 | Redis | `wsl --install` 装 WSL2 → `sudo apt install redis-server`（Windows 原生 Redis 版本太老，别用） |
| M8 | Prometheus + Grafana | 官网免安装 zip，解压即用，比 Docker 省事 |
| M9 | vLLM | 先 `wsl --install`；需要 NVIDIA 驱动支持 WSL CUDA。你的 RTX 4060 8G 可跑 `Qwen2.5-1.5B-Instruct` |
| M9 备选 | 如果 WSL 折腾不动 | 先用 Ollama / LM Studio 顶上，但它们**看不到 continuous batching**，M9 的核心收获会打折 |

> 💡 WSL2 一次装好，M6 和 M9 都用得上。等你到 M5 末尾（第 3 周）再动手装，那时你会带着"我为什么需要它"的问题去装，一次就记住。
