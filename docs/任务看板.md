# 任务看板

> **用法**：每完成一个小任务，把 `[ ]` 改成 `[x]`，并在"日期"列写上日期。
> 每周结束看一眼这个文件——**只要 `[x]` 在增加，你就没走错路。**
>
> 状态图例：`[ ]` 未开始 · `[~]` 进行中 · `[x]` 已完成
