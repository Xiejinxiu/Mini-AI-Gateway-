## 怎么用这套文档

1. **先读** `00-学习契约与工作方式.md` —— 规定我们怎么配合，尤其是"三级提示规则"和"硬性禁止"
2. **再读** `01-路线图与里程碑.md` —— 看清 13 个里程碑和 9~10 周的整体节奏
3. **现在就做** `02-环境搭建.md` —— 半小时搞定 M0
4. **然后按顺序** 03 → 04 → 05 → 06，每完成一个任务就去 `任务看板.md` 打勾
5. **笔记写在** `../notes/` 里（触发式，见 00 号文档的格式）

## 一句话记住整条主线

```text
第 1 周   Client → Gateway → 假后端          学到：HTTP / TCP / 转发
第 2 周   Client → Gateway → Qwen/DeepSeek    学到：OpenAI 协议 / 路由 / 抽象
第 3 周   + 流式（逐字输出）                   学到：SSE / 背压 / 超时分层 / 重试
第 4~6 周 + 限流 / 负载均衡 / 可观测性          学到：Redis / 分布式 / Prometheus
第 7 周   + 本地 vLLM                         学到：KV Cache / Continuous Batching
第 8~9 周 + Agent / MCP                       学到：工具调用 / 治理 / 审计
第 10 周  README / benchmark / 复盘文章        学到：技术写作
```

**每增加一个模块，就对应一个新的知识领域。** 而这些知识不是你硬背来的，是你的项目真的遇到了问题，你去解决，然后留下的。
